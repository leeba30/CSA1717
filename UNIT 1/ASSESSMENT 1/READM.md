# Artificial Intelligence – Assessment 1

## Title

**Implementation of Artificial Intelligence Techniques for Intelligent Problem Solving**

## Objective

To study the basic concepts of Artificial Intelligence and apply various AI algorithms and intelligent agent models to solve real-world problems using Python programming.

## Software Used

* Python 3.13

## Tools Used

* Python IDLE

## AI Techniques / Algorithms Used

* State Space Search
* Breadth-First Search (BFS)
* Uniform Cost Search (UCS)
* Backtracking Algorithm
* Intelligent Agent (PEAS Model)

## Problems Implemented

1. Water Jug Problem using State Space Search (BFS)
2. Mars Rover Intelligent Agent using the PEAS Model
3. Eight Queens Problem using the Backtracking Algorithm
4. Smart Cab Booking Agent Simulation
5. Uniform Cost Search (UCS) for Optimal Path Finding

## Result

All the Artificial Intelligence problems were successfully implemented and tested using Python. The programs demonstrated the practical application of search algorithms, intelligent agents, and constraint satisfaction techniques in solving different AI problems. The implementation enhanced the understanding of AI concepts such as state-space representation, autonomous decision-making, optimal path finding, and intelligent problem-solving.
