**Artificial Intelligence – Assessment**
**Title**

**Machine Learning and Reinforcement Learning using Decision Tree Classification and Q-Learning**

**Objective**

To implement and analyze Artificial Intelligence techniques using Decision Tree Classification and Q-Learning. The Decision Tree model is used to classify data based on the Gini Index, while Q-Learning is used to train an agent to learn an optimal policy in a 4×4 Grid World environment through repeated interaction and rewards.

**Software Used**

Python 3.x

**Tools Used**

Python IDLE

**Libraries Used**

• Pandas
• NumPy
• Scikit-learn
• Matplotlib

**Algorithms / Techniques Used**

• Decision Tree Classification
• Gini Index
• Train-Test Split
• Accuracy Score
• Confusion Matrix
• Classification Report
• Q-Learning
• Q-Table
• Epsilon-Greedy Policy
• Cumulative Reward
• Reinforcement Learning

**Problems Implemented**

• Decision Tree Classification using Iris Dataset

• Q-Learning using 4×4 Grid World

**Result**

Successfully implemented and analyzed both Artificial Intelligence problems using Python. The Decision Tree Classification model was trained on the Iris dataset using the Gini Index as the splitting criterion. The model was evaluated using accuracy score, confusion matrix,classification report, and misclassified instances. The Decision Tree successfully classified the Iris flower classes with high accuracy.The Q-Learning algorithm was implemented in a 4×4 Grid World with +10 reward for reaching the goal, −1 for each step, and −5 for obstacles. The Q-table was initialized with zeros and updated over 100 episodes using the learning rate, discount factor, and exploration rate. The Q-values were recorded at Episodes 1, 50, and 100, and the final learned policy was extracted. The cumulative reward graph demonstrated the learning and convergence behaviour of the agent.Overall, the implementation demonstrates how Decision Tree Classification and Reinforcement Learning can be used to solve classification and intelligent decision-making problems in Artificial Intelligence.
