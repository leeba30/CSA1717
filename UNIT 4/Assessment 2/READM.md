**Artificial Intelligence – Assessment**
**Title**

Critical Review and Analysis of Machine Learning Research using Decision Tree Classification

**Objective**

To study and critically analyse a recent peer-reviewed research article related to Decision Tree Classification and Inductive Learning, understand the machine learning methodology and dataset used, evaluate the reported results, identify the strengths and limitations of the approach, and connect the research findings with CO 4 concepts.

**Software Used**

Python 3.x

**Tools Used**

Python IDLE

**Algorithms / Techniques Used**

• Inductive Learning
• Decision Tree Classification
• Gini Index
• Train-Test Split
• Feature Selection
• Data Preprocessing
• Accuracy Score
• Precision
• Recall
• F1-Score
• AUC-ROC
• Confusion Matrix
• Classification Report
• Explainable Machine Learning

**Problem Implemented**

• COVID-19 Classification using Decision Tree and Machine Learning Techniques

The problem focuses on using routine blood-test parameters to classify COVID-19 patients. The Decision Tree approach learns patterns from previously labelled patient data and uses these patterns to make predictions for new patients.

**Result**

The selected research article was successfully studied and analysed with respect to its objective, research gap, methodology, dataset, machine learning techniques, performance measures, strengths, limitations, and real-world applicability.The study demonstrates how Decision Tree-based machine learning techniques can be applied to healthcare diagnosis and classification problems. The model uses patient-related and blood-test features to distinguish between COVID-19-positive and COVID-19-negative cases. Performance was evaluated using measures such as accuracy, F1-score, sensitivity, specificity, and AUC-ROC.The analysis also showed the importance of explainability in healthcare machine learning, since medical professionals need to understand the reasons behind model predictions. The study was connected with CO 4 concepts, particularly Inductive Learning, Decision Trees, and Statistical Learning.Overall, the research demonstrates that machine learning can support intelligent medical decision-making, while also highlighting important challenges such as dataset imbalance, limited sample size, generalization, data privacy, model reliability, and real-world clinical validation.
