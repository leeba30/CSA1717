
**Artificial Intelligence – Assessment**
**Title**

**Logical Reasoning and Automated Theorem Proving using Artificial Intelligence Resolution Algorithm**

**Objective**

To formulate and solve Artificial Intelligence problems using Propositional Logic, Conjunctive Normal Form (CNF), Resolution Algorithm, Resolution Refutation, and logical reasoning techniques.

**Software Used**

Python 3.13

**Tools Used**

Python IDLE

**Algorithms / Techniques Used**

• Propositional Logic
• Resolution Algorithm
• Conjunctive Normal Form (CNF)
• Resolution Refutation
• Negation of Goal
• Empty Clause Derivation
• Logical Inference

**Problems Implemented**

• Rain and Wet Ground using Resolution Algorithm

• Student Assignment Submission using Resolution Algorithm

• Library Membership using Resolution Algorithm

• Placement Eligibility using Resolution Algorithm

• Access Control System using Resolution Algorithm

**Result**

Successfully implemented and analyzed all five Artificial Intelligence problems using the Resolution Algorithm in Python. The given knowledge bases were represented using propositional logic, converted into Conjunctive Normal Form (CNF), and the goals were proved through resolution by contradiction. The Empty Clause (□) was successfully derived in each problem, proving that the ground is wet, Rahul receives internal marks, Priya can borrow books, Arun is eligible for placement, and the user is granted access. The implementation demonstrates how logical reasoning and automated theorem proving can be used to derive valid conclusions from a given set of facts and rules in Artificial Intelligence.
